# 开篇黄金三章设计指南

## 使用路由

- 第 1 章细纲读“第一章：开篇钩子”。
- 第 2-3 章细纲读对应章节目标和检查表。
- 开篇闸门只生成问题和候选改法，是否进入正文由作者确认。

## 核心理念

**前三章决定读者去留**。网文黄金法则：
- **第一章**：钩子+悬念 → 让读者点进来
- **第二章**：金手指+期待 → 让读者留下来
- **第三章**：冲突+爽点 → 让读者追下去

---

## 第一章：开篇钩子

### 设计目标
- 前3秒内抓住注意力（开篇第一句）
- 前30秒建立代入感（主角出场）
- 前300字抛出悬念（章末钩子）

### 钩子类型

| 类型 | 开篇示例 | 适用题材 |
|------|---------|---------|
| **危机开场** | "废物！"一声冷喝，林枫被一脚踹飞。 | 玄幻、爽文 |
| **反差开场** | 三十岁生日这天，陈凡收到了自己的死亡通知。 | 都市、悬疑 |
| **悬念开场** | 尸体被发现时，已经死了三天。 | 悬疑、推理 |
| **冲突开场** | "你确定要退婚？"萧炎盯着纳兰嫣然的眼睛。 | 玄幻、言情 |
| **金手指开场** | 【叮！签到系统激活成功！】 | 系统流、爽文 |
| **重生开场** | 再次睁开眼，叶辰回到了十八岁那年。 | 重生流 |
| **意象开场** | 天上有九轮太阳。今天是它们同时出现的第九天。 | 奇幻、末世 |

### 第一章结构

```
[开篇句] — 钩子，10-30字
[场景建立] — 50-100字，交代环境
[主角出场] — 100-200字，外貌+身份+处境
[核心事件触发] — 200-300字，引发故事的事件
[章末悬念] — 50字，拉读第二章
```

### 第一章禁忌
- 开头大段世界观介绍（读者直接划走）
- 开头大段人物外貌描写（无聊）
- 开头没有冲突或悬念（读者没有读下去的理由）

## 第二章：金手指出场

### 设计目标
- 揭示主角的特殊能力/系统
- 建立读者对未来的期待
- 展示金手指的潜力

### 金手指类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 觉醒型 | 突然获得能力/突破/血脉觉醒 | 剑碑觉醒 |
| 系统型 | 系统激活，面板展示 | 【签到系统已激活】 |
| 重生型 | 带着前世记忆回来 | "我竟然回到了十年前" |
| 物品型 | 获得/发现特殊物品 | 捡到神秘戒指/玉佩/古籍 |
| 传承型 | 获得前辈/大能传承 | 意识进入传承空间 |
| 奇遇型 | 意外遇到改变命运的事件 | 误入秘境/遇到高人 |

### 金手指出场方式

| 方式 | 特点 |
|------|------|
| 危机中觉醒 | 绝境时金手指激活，瞬间逆转（最常见） |
| 日常中触发 | 平凡时刻金手指主动出现（反差感） |
| 他人引发 | 被人暗算/伤害时激活（制造复仇动力） |
| 自我觉醒 | 主角主动探索中发现（适合冷静智慧型主角） |

### 第二章结构

```
[承接第一章悬念] — 50字
[金手指触发] — 100-150字，能力/系统出现的方式
[金手指展示] — 150-200字，能力说明/系统面板
[初步使用] — 100-150字，第一次用金手指
[期待钩子] — 50字，暗示金手指的更大潜力
```

## 第三章：冲突+第一个爽点

### 设计目标
- 建立第一个小冲突
- 展示主角使用金手指后的变化
- 制造第一个爽点（让读者爽到）

### 冲突设计

| 要素 | 说明 |
|------|------|
| 对手 | 第一个小反派（不能太强——太强赢不了；不能太弱——赢了没感觉） |
| 冲突起因 | 对手主动挑衅/利益冲突/保护某人 |
| 冲突过程 | 对手压制→主角使用金手指→局势逆转 |
| 冲突结果 | 有明确的胜利/收获/认可 |

### 第三章结构

```
[日常/承接] — 50-100字
[冲突触发] — 100-150字，冲突事件发生
[冲突升级] — 150-200字，矛盾激化
[主角应对] — 100-150字，使用金手指解决
[爽点收尾] — 50-100字，打脸效果/逆袭感受/获得认可
[拉读钩子] — 更大的冲突或悬念的暗示
```

## 黄金三章检查清单

### 第一章
- [ ] 开篇句是否在30字内抓住注意力？
- [ ] 主角是否在前300字内出场？
- [ ] 主角身份/处境是否清晰？
- [ ] 是否有明确的悬念钩子？

### 第二章
- [ ] 金手指是否清晰明确？
- [ ] 金手指是否有吸引力（读者会想要）？
- [ ] 是否展示了金手指的潜力和限制？
- [ ] 是否有期待感钩子（读者想知道接下来发生什么）？

### 第三章
- [ ] 是否有明确的冲突？
- [ ] 主角是否展现了能力/性格？
- [ ] 是否有打脸/逆袭/获得认可的爽点？
- [ ] 是否有继续追读的动力？

## 开篇常见问题

| 问题 | 表现 | 改进 |
|------|------|------|
| 开局太慢 | 前三章还在铺垫世界观 | 直接在冲突中展示世界观 |
| 没有钩子 | 开头平淡无奇 | 开局即冲突/危机/悬念 |
| 信息堆砌 | 第一章像设定说明书 | 融入剧情，读者需要知道才给 |
| 金手指出太晚 | 第五章才有金手指 | 最晚第三章必须出现 |
| 第一个对手太弱 | 毫无威胁，赢得太轻松 | 让对手有压制主角的阶段 |
| 第一个对手太强 | 靠机械降神才能赢 | 金手指+技巧赢得合理 |
