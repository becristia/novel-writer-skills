# L1 主线规划 4 段式

> 配合 `SKILL.md` §5 Layer 1 入口路由使用。
> 设计故事整体走向的 6 维度：结构/冲突/主角/反派/关键节点/伏笔大布局。

---

## 1. 入口与适用范围

入口触发：
- `"开始做大纲"` / `"重做主线"` / `"修改主线"`

L1 是大纲期第一步——3 层顺序循环中最上游的层。

---

## 2. 4 段式子流程

### 步骤① brainstorming

6 维度 prompt：
- 三幕/多幕结构（开篇 / 发展 / 高潮 / 收尾 / 尾声）
- 故事核心冲突（外冲突 + 内冲突）
- 主角成长曲线（4 阶段：初始 → 挑战 → 转折 → 完成）
- 反派/对手设计（动机 + 弧线 + 终结）
- 关键节点（10-20 个 story beats）
- 伏笔大布局（长线伏笔，10 万字级别回收）

### 步骤② spec

写 `03-大纲/00-主线规划.md`（结构化字段）：
- 主线骨架 / 关键节点表 / 卷划分 / 情绪曲线

### 步骤③ execution

写 spec → 人审 → 写 `进度.json.phases.structure.status = "in_progress"`

### 步骤④ validation

- 跑 `validate_novel_structure_skill.py --template l1-main-plot`（自身）
- 10-20 关键节点覆盖检查（手动或脚本辅助）
- 伏笔大布局完整性 grep
- 跑 `validate_novel_structure_skill.py --template pacing-check`（节奏密度自检段落存在）

---

## 3. 模块特定模板

`03-大纲/00-主线规划.md` 字段速查：
- 三幕结构（开篇 / 发展 1-3 幕 / 高潮 / 收尾 / 尾声）
- 关键节点表（节点 / 章节范围 / 角色 / 事件）
- 卷划分（5-10 卷，每卷核心事件）
- 情绪曲线（开篇 → 收尾的读者情绪值）
- 场景分布（高潮场景 vs 日常场景比例：建议 1:2 或 1:3）

## 4. 衔接

- 上游：novel-design 5 spec（世界观/人物/力量/物品/关系）
- 下游：L2 地图规划（卷划分 + 关键节点拆卷）
- 平行：novel-meta M1 技能演进 / M4 审计

## 5. 反模式

- ❌ **先于 novel-design 设计主线**：主线依赖设定
- ❌ **关键节点过多/过少**：长篇 10-20 个 / 短篇 5-8 个
- ❌ **伏笔大布局缺失**：长线伏笔不在 L1 规划 → L2/L3 难落地
- ❌ **情绪曲线无变化**：从开篇到收尾一条直线 → 读者疲劳
- ❌ **跳过 4 段式直接写 spec**：L1 brainstorming 不全 → 后续 2 层崩塌
- ❌ **无日常场景缓冲**：全是高潮场景 → 读者疲劳；应有 1:2 或 1:3 的日常/高潮比
