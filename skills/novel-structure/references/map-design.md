# L2 地图规划 4 段式

> 配合 `SKILL.md` §5 Layer 2 入口路由使用。
> 设计每地图的 7 维度：核心事件/主角成长/BOSS/关键场景/伏笔操作/情绪曲线/末尾钩子。

---

## 1. 入口与适用范围

入口触发：
- `"做地图"` / `"加新地图"`  （需 L1 已完成）

L2 依赖 L1 主线规划的卷划分。

---

## 2. 4 段式子流程

### 步骤① brainstorming

7 维度 prompt（v3 design §3.3 七大维度）：
- 核心事件（该地图要解决的 1 个核心问题）
- 主角成长（实力/认知/关系的变化）
- BOSS（反派/对手 + 威胁等级）
- 关键场景（3-5 个标志性场景）
- 伏笔操作（埋/收 + 对应编号）
- 情绪曲线（起→承→转→合 情绪值曲线）
- 末尾钩子（抛向下一地图的悬念）

### 步骤② spec

写 `03-大纲/0X-地图X-名称.md`（含 7 维度 + 跨地图衔接七大维度）：
- 核心事件 / 主角成长 / BOSS / 关键场景 / 伏笔计划 / 情绪曲线 / 末尾钩子
- 跨地图衔接：与上一地图的衔接（承接 + 升级）+ 与下一地图的预告（钩子 + 资源）

### 步骤③ execution

写 spec → 人审 → 写 `进度.json.current_map`

### 步骤④ validation

- 跑 `validate_novel_structure_skill.py --template l2-map`（自身）
- 7 维度完整性 grep
- 跨地图衔接双向检查（与上一 + 下一）
- 节奏密度自检：每 10 章 ≤ 3 大场景切换 / 每场景 ≥ 3 章 / 每 10 章 ≥ 1 章日常
- 跑 `validate_novel_structure_skill.py --template pacing-check`

---

## 3. 模块特定模板

`03-大纲/0X-地图X-名称.md` 字段速查：
- 核心事件 / 主角成长 / BOSS / 关键场景 / 伏笔计划 / 情绪曲线 / 末尾钩子
- 跨地图衔接：与上一地图 + 与下一地图

## 4. 衔接

- 上游：L1 主线规划（卷划分 + 关键节点）
- 下游：L3 细纲规划（每章设计）
- 平行：novel-design 01-世界观.md（地点）

## 5. 反模式

- ❌ **先于 L1 设计地图**：地图依赖卷划分
- ❌ **7 维度不全**：缺 BOSS 或缺情绪曲线 → 后续 L3 难写
- ❌ **跨地图衔接单向**：仅检查与下一地图 → 与上一地图脱节
- ❌ **末尾钩子缺失**：地图间无衔接 → 读者脱节
- ❌ **关键场景过多**：每地图 > 5 个标志性场景 → 节奏过密
- ❌ **伏笔操作错**：埋/收混淆 → 后续回收失败
