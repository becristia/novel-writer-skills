# 冲突设计与经典场景指南

## 使用路由

- 设计主线/地图冲突时读“冲突设计”。
- 设计单章场景时读“经典场景”和对应冲突层级。
- 只用作候选库；冲突取舍必须回到当前细纲和作者判断。

## 第一部分：冲突设计

### 冲突的四个层次

```
表层冲突（这一章打什么架？）
    ↓
中层冲突（这段剧情争什么？）
    ↓
深层冲突（这个地图解决什么问题？）
    ↓
核心冲突（全书的主线矛盾是什么？）
```

**每一章至少要有表层冲突。每5-10章推进一次中层冲突。每个地图推进深层冲突。**

### 外部冲突

| 类型 | 说明 | 设计要点 |
|------|------|---------|
| 利益冲突 | 争夺资源/地位/宝物 | 双方都有合理诉求 |
| 理念冲突 | 价值观对立 | 展示双方立场，不纯是好人打坏人 |
| 仇恨冲突 | 血海深仇/灭门之恨 | 仇恨要有具体事件支撑 |
| 生存冲突 | 你死我活 | 制造时间压力和有限的出路 |

### 内部冲突

| 类型 | 说明 | 示例 |
|------|------|------|
| 道德困境 | 对的选择 vs 有利的选择 | 救一人还是救一百人 |
| 身份认同 | 我是谁？我属于哪边？ | 人类血脉+魔族力量 |
| 情感纠葛 | 两段关系之间的选择 | 使命 vs 爱情 |
| 过去阴影 | 创伤记忆阻碍前行 | 因为过去的失败不敢再尝试 |
| 理想现实 | 梦想 vs 生存 | 追求剑道极致还是保护家人 |

### 人际冲突

| 类型 | 触发原因 | 最高潮 |
|------|---------|--------|
| 信任危机 | 怀疑背叛/误会 | 对峙/决裂/真相大白 |
| 利益分歧 | 分配不均/目标不同 | 分道扬镳/妥协 |
| 理念不合 | 做法不同/路线分歧 | 一方证明自己是对的 |
| 嫉妒心理 | 实力差距/待遇不公 | 和解或彻底决裂 |

### 冲突升级原则

```
小摩擦 → 正面冲突 → 矛盾公开 → 一方失利 → 积蓄力量 → 决战
  （铺垫）  （触发）   （升级）   （低谷）   （准备）   （高潮）
```

### 反转设计

#### 四种经典反转模式

**模式一：敌人是亲人**
```
铺垫：敌人对主角有奇怪的态度，手下留情
反转：敌人是主角失散的亲人
效果：情感冲击，进退两难
```

**模式二：恩人是仇人**
```
铺垫：恩人对主角照顾有加，但偶尔露出异常
反转：恩人就是幕后黑手/灭门参与者
效果：世界观崩塌，信念重建
```

**模式三：弱者是强者**
```
铺垫：某人看起来不起眼，但某些细节暗示不简单
反转：隐藏实力，关键时刻出手
效果：惊喜，重新审视之前的线索
```

**模式四：正义是邪恶**
```
铺垫：正派人士行为逐渐可疑
反转：所谓的正派才是真正的反派
效果：颠覆认知，灰色世界观
```

## 第二部分：经典场景设计

### 场景的起承转合

```
【起】铺垫引入（15-20%）
  交代背景、引入冲突、制造期待

【承】发展推进（25-30%）
  冲突升级、悬念加深、情绪积累

【转】冲突高潮（35-40%）
  矛盾爆发、高潮迭起、情绪释放

【合】结局收尾（15-20%）
  结果呈现、伏笔埋设、承上启下
```

---

### 场景一：拍卖会

**核心爽点**：财富展示、打脸装逼、获得宝物

| 阶段 | 内容 |
|------|------|
| 起 | 拍卖会开始，展示拍卖品，各路势力入场 |
| 承 | 前几件拍品竞价，反派炫耀实力和财富 |
| 转 | 关键拍品出现，主角与反派激烈竞价，亮出底牌碾压 |
| 合 | 主角获得拍品，反派丢脸，拍品的隐藏价值暗示 |

**变体**：
- 主角是卖家而非买家
- 拍品是假的/陷阱
- 拍卖会被袭击（转为战斗场景）

---

### 场景二：比武/宗门大比

**核心爽点**：展现实力、打脸对手、获得荣誉

| 阶段 | 内容 |
|------|------|
| 起 | 比赛规则介绍，对手匹配，观众期待 |
| 承 | 前几轮比赛，展现实力差距，暗中观察 |
| 转 | 关键比赛（决赛/主角打最被看好的人），激烈对决 |
| 合 | 获胜/意外结果，奖励颁发，新的关注/威胁 |

**设计要点**：
- 对手要有层次（炮灰→小强→势均力敌→黑马）
- 每场战斗有不同的看点（不要重复）
- 最终决战要有意外变数（打破预期）

---

### 场景三：秘境/遗迹探险

**核心爽点**：冒险、机缘、危机

| 阶段 | 内容 |
|------|------|
| 起 | 秘境出现/开启，各方势力涌入 |
| 承 | 外围探索，小收获，小危险 |
| 转 | 深入核心区域，遇到真正危险，机缘出现 |
| 合 | 获得核心传承/宝物，逃离/击败守护者，秘境崩塌 |

**设计要点**：
- 秘境有明确的"主人"和"由来"（不只是随机副本）
- 机缘和危险要成正比
- 设置"只有主角能通过"的关卡（发挥金手指的作用）

---

### 场景四：悟道/突破

**核心爽点**：实力质变、心境提升

| 阶段 | 内容 |
|------|------|
| 起 | 遭遇瓶颈/契机出现 |
| 承 | 回顾过往，内心挣扎 |
| 转 | 顿悟时刻（触发：一句话/一个画面/一种感受） |
| 合 | 突破完成，实力质变，新的视野 |

**设计要点**：
- 悟道之前必须有积累和困惑
- 悟道契机要有铺垫（之前出现过的某句话/某个画面）
- 突破之后要有确认（展示新能力/新视角）

---

### 场景五：生死危机/绝地反击

**核心爽点**：紧张刺激、逆转获胜

| 阶段 | 内容 |
|------|------|
| 起 | 危机降临，主角陷入绝境 |
| 承 | 尝试常规应对，全部失败，绝望加剧 |
| 转 | 放弃/牺牲→意外转机（金手指/同伴/伏笔回收） |
| 合 | 逆袭成功，化险为夷，新的认识/成长 |

---

### 场景六：复仇打脸

**核心爽点**：情绪释放、爽感十足

| 阶段 | 内容 |
|------|------|
| 起 | 回顾仇恨/不公遭遇（篇幅适中，不要过度重复） |
| 承 | 积蓄力量/等待时机 |
| 转 | 打脸时刻——实力碾压、当众揭露、身份揭秘 |
| 合 | 后果/余波，新的冲突种子 |

---

### 场景七：情感高潮

**核心爽点**：情感爆发、关系变化

| 阶段 | 内容 |
|------|------|
| 起 | 情感积累的临界点 |
| 承 | 触发事件（一方遇险/即将分离/重大误会） |
| 转 | 情感爆发（表白/争吵/和解/告别） |
| 合 | 关系确立或改变，新的情感状态 |

---

## 场景设计自检

- [ ] 每个关键场景是否有完整的起承转合？
- [ ] 场景类型是否多样化（不要连着两个同类场景）？
- [ ] 每个场景是否推进了剧情或人物？
- [ ] 高潮场景的铺垫是否充足？
- [ ] 场景之间的衔接是否自然？
