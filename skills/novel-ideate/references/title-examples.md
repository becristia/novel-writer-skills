# 网络小说书名案例库

## 使用路由

- 生成书名候选时按“身份/动作/系统/反差/悬念/情感/意境”抽样。
- 评估书名时只读对应类型的分析和命名公式。
- 不要复制案例书名结构到不可区分的程度。

## 一、身份型

突出主角的身份、地位或独特性。

| 书名 | 分析 |
|------|------|
| 《全职高手》 | "全职"定义身份，"高手"定义水平，简洁有力 |
| 《斗破苍穹》 | "斗"是动作也是身份（斗者），"破苍穹"是目标 |
| 《武动乾坤》 | "武"定义领域，"动乾坤"展示格局 |
| 《大奉打更人》 | "打更人"是独特职业身份，有辨识度 |
| 《诡秘之主》 | "之主"暗示掌控者身份，"诡秘"定调 |

**命名公式**：`[领域/身份] + [格局/目标]`

---

## 二、动作型

突出核心动作或变化。

| 书名 | 分析 |
|------|------|
| 《吞噬星空》 | "吞噬"是核心动作，有侵略性和想象空间 |
| 《完美世界》 | "完美"是追求目标，暗示理想 |
| 《遮天》 | 二字封神，"遮"是动作，格局巨大 |
| 《一剑独尊》 | "一剑"是方式，"独尊"是结果 |
| 《签到成帝》 | "签到"是动作（金手指），"成帝"是结果 |

**命名公式**：`[核心动作] + [目标/结果]`

---

## 三、系统型

突出金手指（系统/签到/抽奖等）。

| 书名 | 分析 |
|------|------|
| 《签到成帝》 | 直接告诉读者：签到就能成帝 |
| 《开局签到荒古圣体》 | 信息完整：开局+签到+圣体 |
| 《我的系统是外挂》 | "系统"+"外挂"，双倍金手指暗示 |
| 《系统之掌门模拟器》 | 系统+身份（掌门）+玩法（模拟器） |
| 《每天一个签到奖励》 | 节奏感：每天都有 |

**特点**：信息量大（6-10字常见），直接告知金手指类型。

---

## 四、反差型

制造前后对比和反差感。

| 书名 | 分析 |
|------|------|
| 《废柴逆袭》 | 经典反差：从废到强 |
| 《从废物到天帝》 | 起点-终点明确 |
| 《最强废柴》 | 矛盾修辞，吸引点击 |
| 《开局就被退婚了》 | 危机开局，制造同情和好奇 |
| 《我只是个凡人啊》 | 自嘲式标题，暗示实际上很强 |

**命名公式**：`[低起点] + [高目标]` 或 `矛盾形容词 + 身份`

---

## 五、悬念型

制造好奇心，让人想点进去。

| 书名 | 分析 |
|------|------|
| 《诡秘之主》 | "诡秘"制造悬疑氛围 |
| 《神秘复苏》 | 什么东西复苏了？ |
| 《我有一座恐怖屋》 | 恐怖屋+我有=想看看怎么回事 |
| 《十日终焉》 | 十日会发生什么？终焉是怎样的？ |
| 《谁让他修仙的！》 | 反问句式，制造好奇心 |

**命名公式**：`[神秘元素] + [模糊指向]` 或 `反问/感叹句`

---

## 六、情感型

突出情感线和人物关系。

| 书名 | 分析 |
|------|------|
| 《何以笙箫默》 | 化用古诗词，有文化感 |
| 《微微一笑很倾城》 | 画面感，甜宠暗示 |
| 《你是我的荣耀》 | 第二人称，共情感强 |
| 《杉杉来吃》 | 谐音梗，轻快有趣 |

**特点**：通常偏文艺，字数4-7字，有画面或情感暗示。

---

## 七、意境型

营造氛围和画面，通常短而有力。

| 书名 | 分析 |
|------|------|
| 《剑来》 | 二字封神的典范，简单但有气势 |
| 《雪中悍刀行》 | 画面感：雪中+悍刀+行 |
| 《将夜》 | 一字定调，"将"有临界的意味 |
| 《间客》 | 简洁，有间谍和过客的双重暗示 |
| 《诛仙》 | 二字封神，动作+对象 |

**命名公式**：`[意象名词] + [动作]` 或 2-3字高度凝练

---

## 书名设计检查清单

- 朗朗上口吗？读出来顺不顺？
- 体现核心卖点吗？读者能不能猜到类型？
- 容易记住吗？读者看完能不能复述？
- 有辨识度吗？在书海中能不能被注意到？
- 符合题材风格吗？玄幻要有力量感，言情要有情感温度？
- 搜索友好吗？是否有生僻字或容易打错？
