# 对话写作技巧指南

## 使用路由

- 起草对话前读“五大原则”。
- 修改人物口吻时读“角色声线”和反模式。
- 阶段 B 软性自检只列疑点，不替作者判死刑。

## 一、对话五大原则

### 原则1：每句对话都要有目的

| 目的 | 说明 | 示例 |
|------|------|------|
| 推动剧情 | 揭示信息/推进事件 | "他往东边去了。" |
| 展现性格 | 体现人物特点 | "这点小事，何必惊动老爷子？" |
| 制造冲突 | 引发矛盾对立 | "你凭什么管我？" |
| 建立关系 | 展示人物亲疏 | "哥，我回来了。" |
| 埋设伏笔 | 暗示未来事件 | "你长得真像他..." |

**自我检查**：如果一句对话删掉不影响任何东西——删掉它。

### 原则2：对话要有节奏

```
快节奏：短句（不超过10字）、少描写穿插、连续对话
  → 战斗/冲突/紧急场景

慢节奏：舒句（可超30字）、穿插动作和描写、停顿
  → 情感/铺垫/日常场景
```

**节奏转换技巧**：
- 快→慢：对话中突然插入一段安静描写
- 慢→快：对话被突发事件打断

### 原则3：潜台词比明说更有力

| 表面意思 | 潜台词 | 读者感受 |
|---------|--------|---------|
| "你饿吗？" | "我饿了，去做饭" | 会心一笑（委婉有趣） |
| "他是个好人。" | "他是个傻子" | 讽刺效果 |
| "你看着办吧。" | "你必须按我说的做" | 感受到威胁 |
| "随便你。" | "我很生气" | 情绪张力 |

**潜台词技巧**：
- 说反话：表面肯定，实际否定
- 顾左右而言他：回避真正话题
- 反问：用问题回答问题
- 沉默：不说话也是对话，有时沉默比任何话都有力

### 原则4：每个人物要有独特语气

| 人物类型 | 语气特点 | 用词习惯 | 句式偏好 |
|---------|---------|---------|---------|
| 老者 | 稳重简洁有威严 | 文言夹杂 | 短句、判断句 |
| 少年 | 活泼直接有冲劲 | 口语化 | 感叹句、反问句 |
| 谋士 | 委婉含蓄有深意 | 偏书面 | 长句、假设句 |
| 武者 | 直爽粗犷有力量 | 简洁粗暴 | 短句、祈使句 |
| 冷面角色 | 话少冷硬 | 精简到极致 | 1-5字句 |

**语气设计方法**：
- 独特口头禅（每重要人物1个）
- 句式偏好（长/短/问/叹）
- 称呼习惯（对同一人可以有不同称呼体现关系）

### 原则5：对话要制造张力

**张力来源**：
- 信息差：A知道B不知道的事
- 目标冲突：A和B想要不同的结果
- 立场对立：A和B站在对立面
- 情感矛盾：A对B有复杂情感

**张力技巧**：
- 打断：在关键时刻打断对话
- 误解：让人物产生误解
- 反转：对话结果出人意料
- 悬念：核心问题一直被回避

## 二、对话写作流程

### 1. 明确对话目的

```
这段对话要达成什么？
→ 揭示什么信息？展现什么性格？制造什么冲突？
```

### 2. 确定人物状态

```
参与人物：
  主导者：[谁在推动对话]
  被动者：[谁在回应]
  旁观者：[谁在观察]

情绪状态：[愤怒/平静/紧张/轻松]
隐藏目的：[想要什么/不想暴露什么]
```

### 3. 设计对话结构

```
开场（怎么开始的）→ 发展（怎么推进的）→ 高潮（冲突爆发/信息揭示）→ 收尾（怎么结束的）
```

### 4. 填充对话 + 动作

对话不要是"纯对话"，要穿插动作和表情：

```
✅ 好：

他猛地抓住她的手腕："你疯了吗？"

她没有挣扎，只是静静地看着他："放手。"

"你知不知道这样会害死多少人？"他的声音在颤抖。

"我知道。"她轻轻挣开他的手，"但我别无选择。"
```

### 5. 润色优化

- [ ] 每句都有目的？
- [ ] 节奏合适？
- [ ] 人物语气独特？
- [ ] 有潜台词？
- [ ] 有张力？

## 三、特殊对话类型

### 冲突对话
- 短促、尖锐、有攻击性
- 多用反问句、打断对方、情绪逐步升级
- 对话与动作穿插（对峙时身体语言同样重要）

### 情感对话
- 细腻、含蓄、有温度
- 多用停顿、欲言又止、环境烘托
- 说出来的话比没说出来的少

### 信息对话（最容易写得无聊）
- 分段传递（不要一次说完）
- 穿插听者的反应（不只是听，还要反应）
- 用比喻和例子解释复杂设定

### 幽默对话
- 夸张、反转、节奏克制
- 吐槽、冷幽默、反差萌

## 四、对话常见问题

| 问题 | 表现 | 改进 |
|------|------|------|
| 对话平淡 | 像念说明书 | 加入情绪和潜台词 |
| 语气雷同 | 所有人说话方式一样 | 给每人设计独特语气 |
| 信息堆砌 | 对话变成设定讲解 | 分段传递，穿插反应 |
| 缺乏动作 | 只有说话 | 穿插表情、动作、场景 |
| 过度解释 | 把潜台词也说出来 | 相信读者能读懂 |

## 对话润色示例

### 润色前
```
"你为什么要这样做？"
"因为我必须这样做。"
"但是这样会伤害很多人。"
"我知道，但我别无选择。"
```
*（纯对话，无情绪，语气雷同）*

### 润色后
```
他猛地抓住她的手腕，指节发白："你疯了吗？"

她没有挣扎。只是抬起头，静静地看着他。
那种眼神他见过——五年前，她决定离开家的那个晚上。

"放手。"她说。不是愤怒，不是哀求，只是平静地陈述一个事实。

"你知道这样会害死多少人吗？"他的声音里有裂缝。

"我知道。"她轻轻挣开他的手，像挣开一片落叶，"但我别无选择。"

他愣在原地，看着她转身离去。
第一次，他感到如此无力。
```
*（加入动作+表情+环境+节奏变化+情感层次）*
