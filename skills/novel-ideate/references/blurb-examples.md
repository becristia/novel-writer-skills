# 网络小说简介案例与设计指南

## 使用路由

- 设计简介候选时读“结构公式”和对应题材示例。
- 做质量复查时读“常见问题”和“修改方向”。
- 不要整篇照搬案例；只抽取结构和钩子方式。

## 简介的核心作用

简介是书名之后的第二道筛选：
- **书名**让人点进来
- **简介**让人开始阅读第一章
- 前300字决定读者去留

## 一、玄幻/仙侠类简介

### 结构公式

```
[开篇钩子] — 1-2句，制造好奇或冲突
[主角处境] — 身份、困境、转折
[金手指] — 获得了什么特殊能力
[爽点预告] — 升级、打脸、逆袭
[一句话卖点] — 核心差异化总结
```

### 示例1：升级流

```
林枫穿越到修真世界，成为青云宗最废柴的外门弟子。
眼看要被逐出宗门，识海中突然浮现一座神秘剑碑——

剑碑之中，竟藏着前世剑神的完整传承。
从此，
灵石不够？剑碑里斩一剑就有。
功法太差？剑碑里刻着失传的九天剑诀。
敌人太强？前世是剑神，这辈子还是剑神！

只是林枫不知道，剑碑的真正秘密，远比剑神传承更加震撼...
```

### 示例2：重生复仇流

```
叶辰死了。
死在最信任的人手里——他的师父，和他的未婚妻。

再次睁开眼，他回到了十八岁那年。
一切还没有发生，一切还来得及。
前世百年修炼经验，今生的每一步都是最优解。

这一次，
他要让所有背叛他的人，付出代价。
他要走到前世的尽头，看看那扇门后，到底是什么。
```

## 二、都市/系统类简介

### 结构公式

```
[穿越/重生/觉醒] — 触发事件
[系统激活] — 系统提示（用【】框起来）
[系统功能] — 能做什么
[冲突/困境] — 面临什么挑战
[爽点展开] — 怎么用系统解决
```

### 示例1：签到系统流

```
陈凡穿越了，带着一个签到系统。
【叮！天剑宗签到成功！获得：九转金丹x1】
【叮！藏经阁签到成功！获得：大日剑诀（神级）】
【叮！掌门密室签到成功！获得：千年修为】

别人苦苦修炼，他每天遛弯签到。
别人拼死拼活，他坐等系统奖励。

直到有一天，签到系统提示：
【叮！新签到地点已解锁：九天之上·天帝宫】
陈凡："？？？你让我签到哪里去？？？"
```

### 示例2：都市异能

```
三十岁生日那天，林北收到了一份礼物——
能看到每个人"剩余寿命"的能力。

从此，他眼里每个人都有两个数字：年龄，和倒计时。
直到在街角咖啡店，他看到了一个女孩，
她的倒计时显示：00:00:03。

三秒后，她死在了林北面前。
而凶手，带着同样的能力。
```

## 三、悬疑/推理类简介

### 结构公式

```
[悬念事件] — 异常事件发生
[主角介入] — 为什么被卷入
[矛盾/谜团] — 看起来不可能/矛盾的地方
[探索方向] — 暗示解谜过程
[终极悬念] — 最后的钩子
```

### 示例

```
尸体被发现时，已经死了三天。
但监控显示，死者三天来每天正常上班、吃饭、回家。

刑侦队长陈默接手了这起"不可能的案件"。
越深入调查，越多无法解释的细节：
死者的手机仍在收到消息，
死者的社交媒体仍在更新，
死者昨天还在跟同事讨论下周的计划。

"你认为，什么情况下，一个死了三天的人还能像正常人一样生活？"
"除非...死的不是他。"
"或者，活着的不是他。"
```

## 四、言情类简介

### 结构公式

```
[相遇] — 怎么认识的
[性格/身份反差] — 为什么有看头
[情感升温] — 甜蜜/虐心瞬间
[阻碍/危机] — 什么考验这段感情
[情感钩子] — 让人想知道结局
```

### 示例

```
苏念是全校最普通的女生——成绩中游，长相中上，存在感为零。
顾深是全校最耀眼的存在——学霸、校草、篮球队长。

两条平行线，因为一次阴差阳错的"被表白"，纠缠在了一起。

"我不是故意的，你能不能当没听到？"
"不能。"
"为什么？"
"因为我当真了。"

从假装情侣到真正心动，
从小心翼翼到奋不顾身。
后来苏念才知道，那场"阴差阳错"，
是顾深精心策划了三个月的"意外"。
```

## 简介写作要诀

### 必须包含的元素

1. **钩子**：前1-2句就要抓住注意力
2. **金手指/特殊设定**：让读者知道这个故事有什么不一样
3. **爽点预告**：让读者期待接下来会有什么好戏
4. **悬念/钩子**：结尾要让人想点开第一章

### 必须避免的问题

| 问题 | 表现 | 改进 |
|------|------|------|
| 太长 | 超过300字 | 删减非关键信息 |
| 太短 | 少于80字 | 补充钩子和爽点 |
| 没有钩子 | 平铺直叙 | 开头制造悬念或冲突 |
| 信息堆砌 | 像设定说明书 | 融入故事感的叙述 |
| 没有卖点 | 看不出为什么该读 | 突出金手指或独特设定 |

### 字数建议

| 类型 | 建议字数 |
|------|---------|
| 手机端显示 | 80-150字（折叠前可见部分最关键） |
| 完整简介 | 150-300字 |
| 极限 | 不超过400字 |

### A/B测试

建议准备2-3个版本的简介，各有侧重：
- 版本A：重金手指
- 版本B：重冲突和悬念
- 版本C：重人物和情感

不同的平台和读者群可能对不同类型的简介反应不同。
