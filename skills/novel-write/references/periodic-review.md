# 周期性大局复盘指南

## 使用路由

- 到 50 章或地图结束时读“复盘维度”。
- 追踪/门禁异常时读“追踪系统审计”和“状态机门禁审计”。
- 暂存区处理只给建议，入库、观察或归档必须作者确认。

## 复盘触发

每完成约50章（或一个地图/卷结束时，取先到者），暂停写作，进行一次大局复盘。

---

## 复盘维度

### 一、人物漂移检查

**问题**：写了50章后，人物有没有悄悄变成另一个人？

| 角色 | 设定性格（第1章） | 当前实际表现 | 漂移程度 | 处理 |
|------|----------------|------------|---------|------|
| 主角 | | | 无/轻度/中度/严重 | 接受进化/拉回/修改词条 |
| 反派 | | | | |
| 女主/CP | | | | |

**检查方法**：
- 读第1章和第N章的同一个角色场景
- 问：如果这是同一个人，中间的变化有合理的原因吗？还是单纯"写忘了"？

**轻度漂移**（1-2个性格特征变化但有铺垫）→ 接受，更新词条
**中度漂移**（明显偏离但方向合理）→ 在复盘后章节加入过渡/解释
**严重漂移**（完全不是同一个人了）→ 标记需修改章节，回溯修正

### 二、伏笔追踪审计

**问题**：有没有埋了忘了的伏笔？有没有该回收的超期了？

- 逐条检查 `追踪/伏笔.md`
- 标记超期未回收的（计划回收章 < 当前章）→ 决定：加快回收 / 调整回收计划 / 改为废弃标记（需用户确认）
- 检查是否有"悄悄回收"的伏笔（回收了但伏笔表没更新）

### 二点五、追踪系统审计

**问题**：续写状态是否还能支撑下一章？

- `追踪/当前上下文.md`：当前焦点、下一步、开放问题是否与最近摘要一致
- `追踪/时间线.md`：故事时间、地点移动、角色行程是否有冲突
- `追踪/角色状态.md`：角色位置、能力、关系、情绪是否与知识库和正文一致
- `追踪/伏笔.md`：伏笔状态是否与本章细纲和正文一致
- `追踪/情节线.md`：主线、支线、人物弧光、关系线是否有断线
- `追踪/写作任务.md`：是否存在长期停留在 drafting/self_checked/human_review 的任务
- 发现冲突时先生成修正建议，交作者确认；不得直接覆盖正式知识库

### 二点六、状态机门禁审计

**问题**：状态机是否准确反映人审进度？

- 检查 `workflow_gates.chapters.<场景任务ID>` 是否按 `outline_ready → draft_ready → self_check_passed → human_finalized → knowledge_reviewed` 顺序推进
- 若 `human_finalized=true` 但 `knowledge_reviewed=false`，提醒知识库/追踪更新还没收尾
- 若任务矩阵显示 `kb_reviewed` 但 gate 未同步，生成修正建议；AI 不直接改 gate
- 若 gate 阻塞，复述 `blocked_reason` 并请作者决定下一步

### 三、节奏健康检查

**问题**：最近50章的节奏还正常吗？

| 指标 | 健康范围 | 实际 | 判断 |
|------|---------|------|------|
| 平均章字数 | 3000-5000字 | | |
| 爽点间隔 | ≤3章 | | |
| 高潮间隔 | ≤20章 | | |
| 日常章节占比 | 10-20% | | |

### 四、世界一致性审计

**问题**：世界观有没有悄悄崩溃？

- 实力体系：后期小兵是不是比前期BOSS还强了？（战力通胀）
- 经济体系：主角的钱还合理吗？有没有无限金手指却还在用之前的货币体系？
- 地理逻辑：50章走遍半个大陆，时间线还合理吗？

### 五、感情/关系线检查

**问题**：重要的关系线有没有被遗忘？

- 女主/CP：最近N章有没有互动？关系有进展还是停滞？
- 关键配角：还有戏份吗？还是被遗忘了？
- 反派：还有威胁感吗？还是已经弱到不值得写？

### 六、知识库同步检查

**问题**：知识库和正文一致吗？

- 抽查5个活跃词条的"当前状态" vs 正文实际描述
- 检查 `_index.md` 是否与各词条一致
- 暂存区盘点：超过30章无新证据的条目 → 生成归档建议或继续观察建议；不得删除，必须等待用户确认

---

## 复盘输出

生成简短复盘报告，提交人审：

```markdown
## 复盘报告 — 第X章（约50章标记）

### 核心发现
1. [最重要的1-3个发现]

### 需要人决策
1. [漂流严重的人物] → 拉回还是更新词条？
2. [超期伏笔] → 加快回收还是调整计划？
3. [其他需要决策的问题]
4. [暂存区盘点] → 哪些提案入库、继续观察或归档？
```

---

## 复盘后的修正

复盘报告人审通过后，执行修正：
- 词条更新 → 知识库
- 追踪更新 → `追踪/当前上下文.md`、`追踪/伏笔.md`、`追踪/时间线.md`、`追踪/角色状态.md`、`追踪/情节线.md`、`追踪/写作任务.md`
- 节奏问题 → 后续细纲调整
- 人物漂移 → 已写章回溯标记（终审时处理）
- 暂存提案 → 用户确认后入库、继续观察或归档；不自动删除
