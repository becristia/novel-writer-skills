# Inspiration：灵感捕获与讨论（v0.4）

## 核心理念

inspiration 是 v3 体系的"灵感收集器"——**任何时候可调**（不与 novel-ideate 冲突）。AI 只负责记录、追问、反驳和整理，不能替作者判断灵感是否进入正式设定。

5 步生命周期（**顺序执行，不可跳**）：
1. **灵感输入**（用户说任意想法）
2. **6 维度分类**（人物/情节/伏笔/世界/金句/其他）
3. **双人对谈**（主代理化身书评人，主动反驳）
4. **写入灵感卡**（使用 `assets/灵感/灵感卡.md` 模板）
5. **状态迁移**（active / dormant / promoted，必须用户确认）

3 态生命周期（灵感卡的当前状态）：
- **active**（刚捕获或讨论中）
- **dormant**（暂存区，暂不使用）
- **promoted**（已升级为正式 card 或纳入 5 问）

## 整体架构图

```
用户灵感输入
    ↓
inspiration（v0.4 新建）
    ├─ 6 维度分类写入项目根 灵感/<类型>/
    ├─ 双人对谈（书评人模式）
    ├─ 升级建议 → 用户确认 → novel-design 正式 card
    └─ 轻量集成 novel-ideate 5 问 brainstorm（读取灵感库）
```

## 入口路由

| 用户说 | 路由到 |
|---|---|
| "灵感：X 是 Y 性格，但有 Z 秘密" | 步骤① 灵感输入（任意输入）|
| "记一下..." / "灵感..." / "..." | 步骤① 灵感输入 |
| "灵感分类" / "这是人物还是情节？" | 步骤② 6 维度分类 |
| "讨论这个灵感" / "展开聊聊" | 步骤③ 双人对谈 |
| "升级为正式设定" | 步骤⑤ 状态迁移 → promoted |
| "搁置" / "暂存" | 步骤⑤ 状态迁移 → dormant |
| "inspiration 是干嘛的" | — | 解释类 |

## 调用前自检

主代理在调用 inspiration 前读：

1. 项目根目录可写（`灵感/` 子目录；不存在则初始化目录提案）
2. 灵感卡模板可用（`assets/灵感/灵感卡.md` 模板已存在）
3. 用户有明确输入（任意灵感文本）
4. 写入前确认灵感归属：全局灵感库 / 当前项目讨论记录 / 只讨论不落盘

## 灵感生命周期（5 步）

### 步骤① 灵感输入

入口：用户说"灵感" / "记一下" / "..." (任何输入)
- 用户输入任意灵感（模糊/明确/片段均可）
- 主代理不立即分类，先接收

产出：原始灵感文本

### 步骤② 6 维度分类

入口：用户已输入灵感
- 主代理用 6 维度 prompt 反问（详见 references/灵感分类.md）
- 用户确认 1 个或多个类型
- 写入项目根 `灵感/<类型>/` 子目录（人物/情节/伏笔/世界/金句/其他）

产出：分类结果 + 写入目录

### 步骤③ 双人对谈（书评人模式）

入口：分类完成
- 主代理化身书评人：3 引导 + 3 反驳
- 用户选择采纳/反对/搁置
- 详见 references/双人对谈.md

产出：对话记录 + 调整后的灵感描述

### 步骤④ 写入灵感卡

入口：双人对谈完成
- 使用 `assets/灵感/灵感卡.md` 模板
- 填充：灵感描述 / 类型 / 关联词条 / 用户批注 / 状态 / 主代理对话记录
- 写入：项目根 `灵感/<类型>/<灵感简述>.md`

产出：灵感卡文件

### 步骤⑤ 状态迁移

入口：灵感卡已写入
- 3 态迁移：active（继续讨论）/ dormant（暂存区待用）/ promoted（升级为正式 card）
- promoted 时：只生成升级建议；用户确认后再调用 novel-design / novel-ideate 流程
- 详见 §6

产出：迁移决策

## 灵感状态迁移

```
active ──────────→ dormant ─────→ promoted
  │                │                │
  │                │                │
  └─ 重新讨论 ←──┘                └─→ 升级为正式 card
                                          (人物/地点/物品/势力/概念)
                                          或纳入 5 问
```

**3 态语义**：
- **active**：刚捕获或讨论中
- **dormant**：暂存区，暂不使用
- **promoted**：已升级为正式 card 或纳入 5 问

**升级路径**：
- promoted 时不自动升级；先让用户确认用途、类型和影响范围，再调 novel-design（写入 `知识库/<类型>/X.md`）或 novel-ideate 步骤②（读入 5 问 brainstorm）
- 升级后灵感卡状态写 "promoted" + 记录升级时间

## 调用频率与触发器

| 项 | 频率 | 自动调用 |
|---|---|---|
| inspiration 步骤①-④ | 高频（任何时候）| 用户主动 |
| inspiration 步骤⑤ | 灵感升级时（用户主动）| 用户主动 |
| 升级到正式 card | 用户明确确认采用时 | 否 |

inspiration **不**被任何自动触发器直接调用——**只被用户手动触发**。

## 错误处理矩阵

| 失败点 | 处理 |
|---|---|
| 灵感输入空 | 拒绝，提示"请输入灵感内容" |
| 6 维度分类不明 | 提示"用 5 维度 prompt 反问" |
| 关联词条失败（指向不存在的 card）| 强约束检查；失败阻断写入 |
| 升级到正式 card 选错类型 | 主代理明确询问类型，**不自动猜** |
| 用户取消双人对谈 | 灵感卡 status = active（保留未讨论内容） |
| 灵感归属未确认 | 只讨论不写文件，等待用户指定归属 |
| 灵感库污染（误写模板或正式 card 位置）| 物理隔离（项目根 `灵感/` vs `assets/灵感/` 模板 vs `知识库/` 正史）|
