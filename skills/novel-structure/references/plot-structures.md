# 情节结构模板大全

## 使用路由

- 主线规划读“三幕式结构”和题材适配结构。
- 地图规划读阶段节点和转折模板。
- 不要套模板替作者决定故事走向；只给结构候选。

## 一、通用三幕式结构

所有故事的基础框架：

```
第一幕：铺垫（前25%）
  开篇钩子 → 世界观建立 → 激励事件 → 第一幕高潮

第二幕：发展（25%-75%）
  冲突升级 → 成长历程 → 中点转折 → 更大危机 → 最低点

第三幕：高潮与结局（75%-100%）
  反击准备 → 终极对决 → 主题升华 → 结局
```

### 各幕要点

| 幕 | 功能 | 关键事件 | 主角状态 |
|----|------|---------|---------|
| 第一幕 | 铺垫 | 激励事件迫使主角行动 | 被动→开始行动 |
| 第二幕 | 发展 | 中点转折改变游戏规则 | 主动→遇到挫折 |
| 第三幕 | 高潮 | 终极对决解决核心冲突 | 全力→胜利/成长 |

## 二、英雄之旅（适合冒险/奇幻）

基于Joseph Campbell的经典模式，适配网文：

```
1. 平凡世界 — 主角的日常
2. 冒险召唤 — 金手指觉醒/意外事件
3. 拒绝召唤 — 主角的犹豫
4. 遇见导师 — 金手指/系统/师父
5. 跨越门槛 — 正式进入修炼/冒险世界
6. 考验、盟友、敌人 — 第一个地图
7. 接近核心 — 接近主线目标
8. 严峻考验 — 第一次重大挫败
9. 获得奖励 — 突破/获得重要的东西
10. 返回之路 — 带着收获回去面对更大的挑战
11. 复活 — 最终蜕变
12. 带着宝物归来 — 宿命对决+结局
```

**适用**：玄幻、仙侠、奇幻 —— 天然有"修炼之路"感的题材。

## 三、升级流结构（适合玄幻/仙侠长篇）

网文最主流的结构模式：

```
地图1：新手村
  └── 入门→立足→小BOSS→突破→换地图

地图2：更大的舞台
  └── 适应→冲突→大BOSS→突破→换地图

...（重复N个地图）

地图N：最终舞台
  └── 宿命对决→巅峰突破→结局
```

### 升级流公式

```
每个地图 = 适应期(1-3章) + 冲突升级(3-5章) + 小BOSS战(2-3章) + 收获期(1-2章) + 换地图钩子(结尾)
```

### 升级流核心

- **实力阶梯清晰**：每个地图对应一个实力层级
- **敌人逐级变强**：从地方恶霸到世界BOSS
- **奖励逐步丰厚**：从灵品到神品
- **世界逐步展开**：从一个小城到整个宇宙

## 四、悬疑/推理结构

```
异常事件发生（钩子）
  ↓
主角介入调查
  ↓
发现矛盾/不可能之处（谜团加深）
  ↓
多条线索并行探索
  ↓
第一个嫌疑人（误导）
  ↓
真相被推翻，回归原点（中点转折）
  ↓
重新审视 → 发现遗漏的关键线索
  ↓
真相逐步浮现（多条伏笔汇聚）
  ↓
最终揭示（反转）→ 高潮
  ↓
余波/新的悬念（可选）
```

**关键原则**：
- 真相必须在之前有伏笔（读者回顾时能发现线索）
- 反转要有铺垫（不能凭空出现）
- 至少一次"误导"让读者以为自己猜到了

## 五、言情/感情线结构

```
相遇（奇特的/有记忆点的第一次见面）
  ↓
相互认识（性格反差、小摩擦）
  ↓
好感萌芽（一起经历某件事）
  ↓
暧昧升温（甜蜜互动、小误会）
  ↓
感情危机（重大误会/外部阻碍）
  ↓
分离/冷战（情绪的谷底）
  ↓
和好（一方主动/真相大白/共同面对）
  ↓
确认关系（高潮）
  ↓
共同面对更大挑战（结局）
```

## 六、系统流特有结构

```
系统激活（第1-2章）
  ↓
新手任务（学会使用系统）
  ↓
任务驱动→升级→新功能解锁（循环）
  ↓
系统升级/进化（中点）
  ↓
发现系统的限制/代价（转折）
  ↓
探索系统的真正来源（深层主线）
  ↓
对抗与系统相关的终极敌人
  ↓
超越系统/与系统和解（结局）
```

## 七、结构选择指南

| 题材 | 推荐主结构 | 可搭配 |
|------|-----------|--------|
| 玄幻 | 升级流 | 英雄之旅 |
| 仙侠 | 升级流 + 三层位面 | 英雄之旅 |
| 都市异能 | 升级流（压缩版） | 接触→深入→对抗 |
| 悬疑推理 | 悬疑结构 | 单元案+主线暗线 |
| 言情 | 感情线结构 | 单元式/分段式 |
| 系统流 | 系统流结构 | 升级流 |
| 群像 | 多线并行 | POV切换 |
