# 跨地图衔接检查指南

## 使用路由

- 地图结束时读“七大衔接维度”。
- 下个地图开写前读战力、情绪、人物状态三项。
- 只生成衔接问题和候选修正，是否改大纲由作者确认。

## 为什么跨地图衔接是结构性致命伤

地图内部写得好 ≠ 全书读起来流畅。地图之间的裂缝——战力断层、情绪断层、人物状态不一致——是读者流失的高危点。

**每个地图末尾和下一个地图开头，是最脆弱的衔接点**。

## 七大衔接维度

### 一、战力衔接

**核心问题**：主角离开地图N时的实力，能否应对地图N+1的初始挑战？

| 检查项 | 数据源 | 健康标准 |
|--------|--------|---------|
| 主角终点境界 | 地图N最后一章 → 词条 `**境界**` | — |
| 地图N+1初始对手境界 | 地图N+1细纲前3章 | ≥ 主角境界 或 主角境界-1小级（可越级） |
| 战力差距 | 对比上述两项 | 差距≤1个大境界 |

**不健康信号**：
- 地图N最终BOSS是剑宗，地图N+1第一个小怪也是剑宗 → 战力通胀
- 主角在地图N结尾突破到剑宗，地图N+1开头被筑基期欺负 → 战力断崖
- 地图N+1的初始挑战远低于主角当前水平 → 没张力

### 二、剧情钩子衔接

**核心问题**：地图N的结尾钩子，在地图N+1的开头兑现了吗？

| 检查项 | 健康标准 |
|--------|---------|
| 钩子兑现 | 地图N结尾的钩子，在地图N+1前3章内至少被提及或推进 |
| 钩子遗忘 | 如果钩子包含"换地图就忘掉的重要信息" → 不合格 |

**常见问题**：
- 地图N结尾："林夜终于知道了父亲的下落——在血魔域" → 地图N+1开头：林夜在血魔域闲逛了10章，完全没提找父亲
- 钩子是"紧迫的威胁"，但换地图后节奏突然变慢

### 三、伏笔传递

**核心问题**：哪些伏笔需要跨地图追踪？

在 `追踪/伏笔.md` 中维护"传递地图"列：

| 编号 | 伏笔 | 埋设地图 | 需传递到 | 传递状态 |
|------|------|---------|---------|---------|
| F005 | 神秘玉佩 | 地图1 | 地图2 | ✅ 已在新地图提及 |
| F008 | 剑尘身份 | 地图1 | 地图3 | ⚠️ 地图2未暗示，跨度太大 |

**健康标准**：
- 每个需传递的伏笔，在新地图的前1/3处至少暗示一次
- 跨2个以上地图的伏笔，每个经过的地图都要有1次暗示（否则读者忘了）

### 四、人物状态衔接

**核心问题**：人物的关系、知识、情绪状态在地图切换时保持一致吗？

| 检查项 | 方法 |
|--------|------|
| 关系一致性 | 对比地图N结尾的"关键关系"表 vs 地图N+1开头的互动描写 |
| 知识一致性 | 主角在地图N知道的事，到地图N+1不能"忘了"（除非有合理原因） |
| 情绪连续性 | 地图N结尾的情绪状态，在地图N+1开头应有承接（可以转变但不能消失） |
| 角色携带 | 地图N结束时和主角在一起的角色，地图N+1开头还在吗？不在了需要说明去向 |

### 五、情绪曲线衔接

**核心问题**：两个地图之间的情绪落差是否合理？

| 过渡类型 | 健康模式 | 不健康模式 |
|---------|---------|-----------|
| 高潮→新地图 | 短暂低落/日常 → 新期待建立 | 高潮后突然踩刹车（情绪断崖） |
| 悲剧→新地图 | 低沉中带着新的希望 → 逐渐回升 | 立刻欢快（情绪矛盾） |
| 日常→新地图 | 平稳过渡 → 新危机引入 | 一直平稳没有冲突（没推动力） |

**检查方法**：读地图N最后半章 + 地图N+1最开始半章。情绪曲线应该是"缓降→平→缓升"，不是"断崖"或"跷跷板"。

### 六、地理和时间衔接

| 检查项 | 问题 |
|--------|------|
| 物理距离 | 从地图N终点到地图N+1起点需要多长时间？合理吗？ |
| 时间跳跃 | 如果两个地图之间有时间跳跃，跳跃中发生了什么？有交代吗？ |
| 信息传播 | 地图N发生的大事（如主角击败BOSS），地图N+1的人知道吗？如果不知道，为什么？ |

### 七、设定扩展一致性

**核心问题**：地图N+1引入的新设定，和地图N的设定矛盾吗？

| 检查项 | 方法 |
|--------|------|
| 力量体系 | 新地图的修炼体系/等级是否和旧地图兼容？ |
| 世界规则 | 新地图是否有"只在本地图成立"的规则？有合理解释吗？ |
| 种族/势力 | 新出现的种族/势力，在旧地图为什么没提到？ |

## 衔接检查流程

### 设计阶段（novel-structure）

在规划两个相邻地图时：

```markdown
## 地图N → 地图N+1 衔接设计

### 战力过渡
- 地图N主角终点境界：___
- 地图N+1初始对手境界：___
- 差距：___ / 合理？___

### 剧情钩子
- 地图N结尾钩子：___
- 地图N+1前3章兑现方式：___

### 伏笔传递清单
| 伏笔编号 | 传递方式 | 地图N+1首次暗示章 |
|---------|---------|-----------------|
| | | |

### 情绪曲线
地图N尾情绪：___ → 地图N+1头情绪：___
过渡设计：___

### 角色携带
地图N结尾与主角同行的角色：___
地图N+1开头这些角色的状态：___
```

### 执行阶段（novel-write 地图审核闸门）

地图N写完、地图N+1开始前，逐项验证：

- [ ] 战力衔接无断层
- [ ] 结尾钩子已在地图N+1前3章兑现
- [ ] 所有需传递的伏笔已在新地图暗示
- [ ] 人物状态前后一致
- [ ] 情绪曲线过渡自然
- [ ] 地理/时间合理
- [ ] 新设定与旧设定无矛盾
